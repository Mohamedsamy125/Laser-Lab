# Laser Lab / Robot Outbreak

نسخة مشروع الويب بـNode.js محليًا وإعداد Vercel جاهز. اللعبة بتفتح من `/`، ومختبر التتبّع من `/lab.html`.

```sh
npm run dev
npm test
npm run build
```

افتح `http://localhost:3000` للتجربة المحلية.
